三级指针指向二级指针

int*** grid 先指向一块 int**，那块二级指针再指向散开的 int*。 上面那一段箭头会在两个二级指针之间移动，下面那一段会从二级指针里的格子移到对应的一级指针。 点任意一格，两段箭头和 plane、row、col 一起改。

int* 指向的 int 块，彼此分开

第一段箭头是三级指针 int*** 指向选中的二级指针 int**。 第二段箭头是这个二级指针里的某个一级指针 int*，指向下面各自独立的 int 块。 块内的 4 个 int 连续。换一块时要跟着另一支指针跳地址，可能缓存不命中。

      int*** grid = new int**[2] 之后，grid[plane] = new int*[3]，grid[plane][row] = new int[4]。
      三级指针每改一次 plane，第一段箭头就换一块二级指针。二级指针每改一次 row，第二段箭头就换一块一级指针指向的 int。
      同一块里改 col，两段箭头都停着，因为指针没变，只是在连续的 4 个 int 里走动，通常缓存命中。
